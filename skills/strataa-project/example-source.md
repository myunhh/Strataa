# Local Notes Demo

This is a self-contained documentation example, not a record of an executed experiment or a user's acceptance. The project described here is illustrative; its statements are observable as document text only.

## Scope and hierarchy

The field is project knowledge management. The problem is losing the connection between project decisions and their supporting local documents. The proposed method is an evidence-linked project manifest. The technique is matching a stored quote to text in a local Markdown source.

## Open question

Can a local manifest make the reason for a proposed project choice traceable without a separate model call in the viewer?

## Hypothesis

A reader may be able to trace a proposed choice if the manifest links the choice to a source and an exact quotation. This is a hypothesis, not a measured outcome.

## Proposed choice and alternatives

The proposal is to keep a UTF-8 JSON manifest inside the project and let the viewer validate and display it locally. The alternative is to ask a model to reconstruct the project's reasoning every time the viewer opens. The proposed rationale is to retain inspectable evidence and avoid repeated semantic analysis in the viewer. No user has accepted this proposal in this example.

## Planned check

The planned check is to open the demo in the viewer and inspect whether the displayed quote occurs in this document. The check has not been run. It would assess traceability of this example only, not whether the proposal improves human learning.

## Current next action

Review the proposed choice and its evidence before deciding whether to adopt it. Do not report the planned check as a result.
